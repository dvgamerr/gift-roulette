# Gift Roulette

โปรเจกต์นี้คือเว็บแอปสำหรับสุ่มจับคู่ผู้ให้และผู้รับของขวัญอย่างง่ายๆ การทำงานคล้ายเกมหมุนวงล้อ คุณสามารถใส่รายชื่อเพื่อนๆ แล้วกดปุ่ม **Spin the Wheel** หรือคลิกวงล้อเพื่อเริ่มสุ่มได้เลย

## วิธีเล่น

1. ใส่ชื่อของผู้เล่นแต่ละคนในช่อง **Participants** โดยพิมพ์หนึ่งชื่อในแต่ละบรรทัด
2. กด **Spin the Wheel** หรือคลิกวงล้อเพื่อสุ่มเลือกชื่อบนวงล้อ
3. ชื่อที่สุ่มได้ครั้งแรกจะกลายเป็นผู้ให้คนปัจจุบัน จากนั้นการหมุนครั้งถัดไปจะเลือกผู้รับและบันทึกลงในรายการ **Gift History**
4. ชื่อของผู้รับจะถูกลบออกจากวงล้อ ทำให้ไม่ถูกเลือกซ้ำ
5. หากต้องการเริ่มใหม่ด้วยรายชื่อเดิม ให้กด **Reset Draw**

## การติดตั้งและพัฒนา

โปรเจกต์สร้างด้วย [Astro](https://astro.build) และรันด้วย Bun

```bash
bun install       # ติดตั้งแพ็กเกจที่จำเป็น
bun run dev       # เริ่มเซิร์ฟเวอร์พัฒนา (http://localhost:4321)
bun run test      # รัน regression tests
bun run build     # ตรวจ type และสร้างไฟล์โปรดักชันในโฟลเดอร์ dist/
bun run verify    # รัน tests, build และ dependency audit ทั้งหมด
bun run preview   # ทดสอบไฟล์ที่ build แล้วแบบโลคัล
```
